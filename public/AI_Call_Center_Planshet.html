Call-Center Ulanish Yo'llanmasi

Haqiqiy o'zbek telefon raqamlarini AI tizimiga integratsiya qilish bo'yicha yo'riqnoma.

1 O'zbekistondan SIP Trunk olish

AI Call Center real qo'ng'iroqlarni qabul qilishi uchun sizga virtual raqam (SIP Trunk) kerak bo'ladi. Uni O'zbekistonning aloqa operatorlaridan olish mumkin:

  • Uztelecom / Beeline Business / Mobiuz / Ucell: Kompaniya nomiga rasmiy shartnoma orqali +998 (71) yoki +998 (55) bilan boshlanuvchi SIP Trunk ulanish liniyasini olish (IP ATS hisob ma'lumotlari: Host, Login, Parol).

2 SIP Gateway o'rnatish

SIP raqamdan kelayotgan audio oqimni (RTP) bizning WebRTC/API tizimiga ulaydigan maxsus shlyuz (Gateway) kerak:

  • SIP.TG Gateway: O'zbek SIP raqamini to'g'ridan-to'g'ri Telegram-ga ulaydigan va Web API taqdim qiladigan eng oson platforma.
  • Zadarma / Twilio SIP Trunking: Kiruvchi qo'ng'iroqlarni Webhook orqali audio oqim ko'rinishida serverimizga yo'naltiradi.
  • Asterisk / FreePBX Server: Agar o'z serveringiz bo'lsa, Asterisk o'rnatib, SIP liniyani ulaysiz va uni n8n webhook-ga bog'laysiz.

3 N8N Integratsiyasi (Logic flow)

Qo'ng'iroq bo'lganda n8n da quyidagi zanjir ulanadi:

[SIP Call Incoming] ➔ [n8n Webhook Node] ➔ [Gemini AI Agent API Node] ➔ [TTS Edge/ElevenLabs API] ➔ [SIP Audio Response Node]

n8n webhook-ga qo'ng'iroq kelganida, mijoz ovozi matnga o'girilib, Gemini-ga yuboriladi. Gemini operator promti bo'yicha javob matnini generatsiya qiladi. Ovozlashtirish dvigateli matnni audio qilib, n8n orqali mijozga qaytaradi.
